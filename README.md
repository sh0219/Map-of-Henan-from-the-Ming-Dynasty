# 明代河南布政使司与汝宁府历史地理资料

本仓库收录一篇关于《明史·地理志》汝宁府记载的考述文章，以及两幅相关历史地图。文章以《明史》不同版本、《明实录》及河南地方志等文献相互参证，对汝宁府的建置沿革、地名、水系和部分记载异同进行考订；两幅地图用于呈现明代河南布政使司及汝宁府的历史地理信息。

## 文件说明

| 文件 | 内容 |
| --- | --- |
| `《明史·地理志》汝宁府考述.pdf` | 围绕汝阳、真阳、上蔡、西平、确山、遂平等地，对《明史·地理志》汝宁府相关记载进行文献比对与考述。 |
| `河南布政使司舆图.png` | 依据谭其骧《中国历史地图集》重新绘制的明代河南布政使司历史地图。 |
| `河南汝宁府校订舆图.png` | 依据《明实录》、河南地方志及多版本《明史》校订地名后重新绘制的汝宁府历史地图。 |
